## 三、字体（全部 SIL OFL 1.1 ✓）

界面按用途分了四套字体，**都已随仓库分发**（OFL 允许再分发）：

| 用途 | 字体 | 文件 | 来源 |
|---|---|---|---|
| 界面默认（档位提示等） | **荆南麦圆体** | `assets/fonts/theme/KNMaiyuan-Regular.ttf` | [maoken-fonts/KNMaiyuan](https://github.com/maoken-fonts/KNMaiyuan) |
| 歌名 / 歌手 | **黑糖话梅** | `assets/fonts/cute/black-sugar-plum-candy/` | OFL.txt 随目录 |
| 状态 / 计时 / 时间日期 | **荆南波波黑** | `assets/fonts/cute/kn-bobohei/` | OFL.txt 随目录 |
| 歌词 | **站酷快乐体** | `assets/fonts/cute/zcool-kuaile/` | OFL.txt 随目录 |

每个字体目录下都有 `meta.json`（字体名、体积、下载来源）和 `OFL.txt`（授权原文）。

**SIL OFL 1.1 允许**：免费使用、修改、再分发（包括商用），
**要求**：保留授权文件、不得单独售卖字体本身、不得用原字体名发布修改版。

### 候选字体（**未随仓库分发**）

`assets/fonts/cute/` 下还评估过另外 5 款可爱字体
（清松手写体6 / 霞鹜漫黑 / 悠哉字体 / 荆南波波黑 / 得意黑 等），

## 五、歌词与封面数据

**歌词、专辑封面**来自 QQ 音乐的公开接口，**运行时实时抓取，不落地存储**。

- 歌词接口：`https://c.y.qq.com/lyric/fcgi-bin/fcg_query_lyric_new.fcg`
- 搜索接口：`https://u.y.qq.com/cgi-bin/musicu.fcg`
- 封面图：`https://y.qq.com/music/photo_new/T002R500x500M000{mid}.jpg`

**说明**：这些不是官方开放 API，是网页端内部接口。使用时注意：
- 不要高频请求（本项目已做 3 秒闸门 + 限流冷却）
- 歌词和封面版权属于版权方，仅供个人播放时显示

本项目**不下载、不存储、不再分发**任何音频文件。
